# Last Asylum — Server 385 Territory Map

Interactive server-wide territory map for **Last Asylum Server 385**.

## Status
The map frontend is installed and ready for GitHub Pages. The shared database/editor backend is intentionally **not** connected to the original map owner's Supabase project.

## Next setup step
Create a separate Supabase project for Server 385, then replace the placeholders in `index.html`:

- `https://PASTE_PROJECT_REF.supabase.co`
- `PASTE_ANON_KEY`

The map ID is already set to `server-385`.

## Hosting
This repository is intended to be published with GitHub Pages from the default branch.
